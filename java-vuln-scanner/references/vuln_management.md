# 组件漏洞 参考资料

本文档收集了关于第三方组件漏洞管理和扫描的资源。

## 漏洞管理
- [NVD (National Vulnerability Database)](https://nvd.nist.gov/)
  美国国家漏洞数据库，提供 CVE 详情。
- [Maven Dependency Mechanism](https://maven.apache.org/guides/introduction/introduction-to-dependency-mechanism.html)
  Maven 官方文档关于依赖机制的说明，有助于理解传递依赖。
- [OWASP Vulnerable Dependency Management](https://owasp.org/www-community/vulnerabilities/Using_Components_with_Known_Vulnerabilities)
  OWASP 关于管理存在已知漏洞的组件的建议。
