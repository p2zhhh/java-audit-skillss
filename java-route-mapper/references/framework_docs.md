# Java 路由映射 参考资料

本文档收集了用于理解和提取 Java Web 框架路由结构的相关官方文档。

## 框架路由文档
- [Spring Web MVC Documentation](https://docs.spring.io/spring-framework/reference/web/webmvc.html)
  Spring 官方文档中关于 `@Controller`、`@RequestMapping` 及其衍生注解的详细说明。
- [JAX-RS (RESTful Web Services) Specification](https://jakarta.ee/specifications/restful-ws/)
  Jakarta EE 关于使用 `@Path`、`@GET` 等注解构建 REST 服务的规范。
- [Apache Struts 2 Documentation](https://struts.apache.org/core-developers/)
  Struts 2 的核心开发指南，包括 Action 映射和 `struts.xml` 配置解析。
