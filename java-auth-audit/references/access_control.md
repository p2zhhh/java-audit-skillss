# Java 鉴权审查 参考资料

本文档收集了用于理解和审查 Java 应用中访问控制机制的相关指南。

## 访问控制指南
- [OWASP Access Control Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Access_Control_Cheat_Sheet.html)
  OWASP 关于如何设计和实现安全访问控制的备忘录。

## 安全框架文档
- [Spring Security Reference Architecture](https://docs.spring.io/spring-security/reference/servlet/architecture.html)
  Spring Security 的官方架构文档，有助于理解其拦截器链和鉴权流程。
- [Apache Shiro Documentation](https://shiro.apache.org/documentation.html)
  Apache Shiro 的官方文档，包含了关于权限配置和过滤器的说明。
